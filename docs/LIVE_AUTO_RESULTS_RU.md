## Интерпретация

AUTO уже включён в приложение на Edge. Для использования нужно установить новую
сборку; push в GitHub сам устройство не обновляет. После начала записи нужны
60 известных running samples мощности для baseline. Тап переключает DRIFT/INTERVALS.
В свободном заезде LAP не требуется. Явные workout/manual источники приоритетны.

Наличие результата в 116 поездках — не оценка точности.
1650/3897 кандидатов короче 30 секунд: стоит проверить,
не дробит ли алгоритм рваную мощность слишком сильно. Некоторые из них могут быть
реальными ускорениями; без независимой разметки нельзя назвать их ложными.
1061 результатов из файлов с timer ambiguity не являются exact replay.
Низкий baseline после coasting, постепенный ramp и малый контраст работы/отдыха
могут объединять или пропускать усилия. Missing power не заменяется нулём.

Физический Edge и читаемость экрана пока не проверены. Следующий шаг — независимая
разметка атак, подъёмов и повторений на обычных поездках, затем prospective проверка
до изменения порогов. Математика DRIFT и FIT-контракты сохранены.
